# raw/

Immutable source material — the ground truth the `wiki/` is distilled from.

- **This entire folder is git-ignored** (except this README). Keep private, copyrighted, or
  large source files here locally / on shared storage; do not commit them.
- Organize by topic: `raw/<topic>/YYYY-MM-DD-descriptive-slug.md` (or `.pdf`, etc.).
- **Read, never modify.** If a source changes, add a new dated file rather than editing.
- Record provenance (URL / DOI / origin) at capture time — the reference wiki page carries it
  forward into frontmatter.

Use `templates/raw-source.md` when capturing pasted text.
